# 🌾 AgroAI — интеллектуальная система мониторинга сельскохозяйственных угодий

## 📌 О проекте

AgroAI — интеллектуальная система для мониторинга и анализа сельскохозяйственных полей.

Система позволяет зарегистрировать поле, указать его координаты, площадь и культуру, получить погодную информацию и провести спутниковый анализ состояния растительности и влажности.

Основной интерфейс системы — Telegram-бот.

## 🚀 Основные возможности

- 🗺 Регистрация сельскохозяйственных полей
- 📍 Хранение координат и границ поля
- 🌱 Указание выращиваемой культуры
- 🌦 Получение погодных данных
- 🛰 Спутниковый анализ Sentinel-2
- 📊 Расчёт индексов NDVI и NDMI
- 🌱 Анализ состояния растительности
- 💧 Анализ влажности растительности
- 📋 Сводная информация по полю
- 💾 Сохранение результатов анализа в базе данных

## 🛰 Спутниковый анализ

Для анализа используются спутниковые данные Sentinel-2.

### NDVI

NDVI используется для оценки состояния и плотности растительности.

### NDMI

NDMI используется для оценки влажности растительности.

Результаты анализа отображаются в Telegram-боте и сохраняются в базе данных.

## 🤖 Telegram-бот

Основное меню системы:

- 🗺 Мои поля
- 🌦 Погода
- 🛰 Спутниковый анализ
- 📊 Сводка поля
